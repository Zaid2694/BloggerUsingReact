# Blogger Using React

A modern, responsive blog application built with **React.js** and **Bootstrap 5**. This project allows users to view blog posts, create new posts, and manage them through a clean and elegant UI.

## 🚀 Live Demo

- **Local Development:** [http://localhost:3000/](http://localhost:3000/)
- **GitHub Repository:** [https://github.com/Zaid2694/BloggerUsingReact](https://github.com/Zaid2694/BloggerUsingReact)

## 🛠️ Technologies Used

- **React.js** (Class & Functional Components)
- **Bootstrap 5** (For responsive UI and styling)
- **React Router DOM** (For seamless client-side routing)
- **Axios** (For API requests to fetch, create, and delete posts)
- **Create React App** (Project bootstrapping)

## ✨ Features

- View a list of blog posts on the Home page.
- Read individual blog posts.
- Create a new blog post (Title, Body, Author).
- Delete existing posts.
- Responsive design powered by Bootstrap 5.
- Simple routing for About, Contact, and Sample Post pages.
